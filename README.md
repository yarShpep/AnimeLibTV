# AnimeLib TV — экспериментальный Android TV-клиент

Нативный прототип для просмотра каталога AnimeLib без полноценного браузера. Приложение не является официальным продуктом AnimeLib и не связано с владельцами сервиса.

## Что уже работает

- каталог популярных аниме и поиск;
- постраничная подгрузка каталога по 60 карточек при приближении к концу сетки;
- фильтрация по жанрам, типу, статусу, годам и сортировке;
- карточка аниме и список серий;
- поиск серии по номеру на странице аниме;
- локальный ряд «Продолжить просмотр» и переходы к предыдущей/следующей серии из плеера;
- загрузка `players[]` для выбранной серии;
- показ только внутренних источников `player=Animelib` с реальным массивом `video.quality[]`;
- выбор любого качества, включая 2160p, только если оно присутствует в API;
- субтитры из `players[].subtitles`: приложение предпочитает ASS, использует VTT/SRT как fallback и позволяет включать/выключать дорожку с пульта;
- воспроизведение MP4 через Media3/ExoPlayer с `Referer`, `Origin` и динамическими Range-запросами;
- VLC через локальный потоковый прокси `127.0.0.1`, который добавляет CDN-заголовки, передаёт 206/Content-Range и отдаёт VLC выбранную subtitle-дорожку через `subtitles_location`;
- VLC получает M3U-очередь «текущая → следующая», поэтому его штатные Next/Previous переключают серии внутри очереди;
- экран не уходит в Ambient Mode/сон во время активного встроенного воспроизведения;
- отдельного верхнего меню в плеере нет: предыдущая/следующая серия переключаются штатными кнопками Media3 с треугольником и чертой;
- кнопка VLC расположена в нижнем ряду рядом с дорожкой и субтитрами; вся панель управления скрывается одним таймером Media3;
- проверка и установка обновлений из GitHub внутри приложения с проверкой SHA-256 и package name;
- OAuth2 PKCE-вход во временном WebView; после callback WebView уничтожается;
- видимый курсор в OAuth WebView: D-pad перемещает указатель, OK/Enter отправляет клик в форму;
- шифрование access/refresh token ключом Android Keystore и автоматический refresh.
- фиксированная landscape-ориентация для Android TV, независимо от виртуального датчика поворота.
- TV-навигация: фокус на поле не открывает клавиатуру до OK, первый Back возвращает каталог наверх, повторный — выходит.

История просмотра хранится только локально на устройстве. Точная позиция сохраняется для встроенного Media3-плеера каждые пять секунд и при выходе из плеера. При просмотре во внешнем VLC приложение не получает позицию VLC через Android Intent, поэтому сохраняется позиция на момент запуска VLC.

## Сборка и установка

Требуются JDK 17 и Android SDK 36.

```bash
./gradlew testDebugUnitTest assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Готовый debug APK после сборки: `app/build/outputs/apk/debug/app-debug.apk`.

## Обновления

Кнопка «Проверить обновления» читает [update.json](update.json). Если `versionCode` выше установленного, приложение потоково скачивает APK, проверяет SHA-256 и package name, затем открывает системное подтверждение Android. При первом обновлении Android попросит разрешить установку из этого источника.

Все будущие APK должны быть подписаны тем же ключом, иначе Android откажется устанавливать обновление. Ключи и токены не должны попадать в Git.

## Важные ограничения

- Без входа AnimeLib часто возвращает только внешние iframe-плееры (например, Kodik). Они намеренно не встраиваются, поэтому прямое воспроизведение в таком случае недоступно.
- OAuth использует web client `client_id=1` и callback на `v5.animelib.org`. Это неофициальный и хрупкий fallback: AnimeLib может запретить WebView, изменить CAPTCHA, callback или правила клиента.
- 4K не гарантируется приложением. Оно показывает 2160p только при наличии соответствующего объекта в `video.quality[]`; URL по суффиксам не угадываются.
- VLC запускается через локальный прокси, поскольку Android Intent не позволяет надёжно передать произвольный `Referer`. Прокси живёт только во время внешнего просмотра и не хранит видео.
- Внешний VLC не возвращает приложению точную позицию или ID выбранного элемента очереди; прогресс в VLC нельзя синхронизировать так же точно, как в Media3.
- Встроенный updater предназначен для sideload-сборок. Публикация в Google Play потребует Play In-App Updates и удаления `REQUEST_INSTALL_PACKAGES`.
- API неофициальный и может измениться без предупреждения. Использование должно соответствовать правилам сервиса, лицензиям контента и законодательству пользователя.

Техническая карта API находится в [research/ANIMELIB_TECHNICAL_REPORT.md](research/ANIMELIB_TECHNICAL_REPORT.md), а прежний отдельный reference-файл — в [research/AnimeLibReference.kt](research/AnimeLibReference.kt).
